A self-contained luxury hospitality theme for The Dog Father Hotel.

== Description ==

The Dog Father is a standalone WordPress theme — no parent theme required.
Upload it, activate it, and you have a finished five-star website. It is
black-first with gold/yellow accents, premium typography, smooth animations,
mobile-first and fast.

The theme renders a complete luxury homepage out of the box (hero, trust bar,
about, services, why-us, stats, gallery, testimonials, FAQ, CTA and contact).
All of that copy is editable from "Dog Father → Homepage" in the WordPress
admin, and every section can be replaced by building the Home page in Elementor.

== Editing ==

Three ways to edit, no code required:

1. Dog Father Control Center plugin → Homepage / Global Settings / Theme
   Settings (colors & fonts) / Services / Gallery / Testimonials / FAQs.
2. Elementor — build any page visually; the theme automatically steps aside and
   renders your Elementor design.
3. The WordPress block editor for normal pages and posts.

== Recommended companion ==

Install and activate the "Dog Father Control Center" plugin, then open
"Dog Father → Setup" and click Run Setup. It creates all pages, menus and demo
content automatically.

== Screenshot ==

Add screenshot.png (1200x900) to the theme root before distributing. It should
show the black hero with the gold gradient headline and the gold "Book Now"
button.
