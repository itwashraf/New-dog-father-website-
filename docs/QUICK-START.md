# Quick Start — Upload & Go

The Dog Father is a **standalone** theme. No parent theme, no Elementor Pro, no
manual page building required. Upload, activate, click once — done.

## 1. Upload the plugin

`WP Admin → Plugins → Add New → Upload Plugin` → upload the
`dog-father-control-center` folder (zip it first) → **Activate**.

## 2. Upload the theme

`WP Admin → Appearance → Themes → Add New → Upload Theme` → upload the
`dog-father` folder (zip it first) → **Activate**.

> On activation the theme automatically triggers setup. If for any reason it
> doesn't, do step 3 manually.

## 3. One-click setup

Go to `Dog Father → Setup` and click **Run Setup Now**. This instantly creates:

- All pages: Home, About, Services, Gallery, Testimonials, Book Now, Contact,
  FAQ, Blog, Privacy Policy, Terms
- Primary + Footer navigation menus (already assigned)
- Home set as the front page, Blog as the posts page
- 6 demo services (with prices & features), 6 testimonials, 6 FAQs
- Homepage content and demo gallery placeholders

Safe to run again any time — it never creates duplicates.

## 4. Make it yours

Everything is editable, no code:

| What | Where |
| --- | --- |
| Business name, phone, WhatsApp, email, address, map, hours | `Dog Father → Global Settings` |
| Brand colors & fonts (apply site-wide instantly) | `Dog Father → Theme Settings` |
| Homepage text, hero image, section show/hide | `Dog Father → Homepage` |
| Services, Gallery, Testimonials, FAQs | `Dog Father → (each menu item)` |
| Bookings, Dog Profiles | `Dog Father → Bookings / Dog Profiles` |
| Pages & menus | `Pages` and `Appearance → Menus` |

That's it — you have a finished luxury website.

## Editing with Elementor (optional)

You do **not** need Elementor. But if you want pixel-level control of any page:

1. Install **Elementor** (the free version is enough).
2. Edit any page → **Edit with Elementor**.
3. The theme automatically steps aside and renders your Elementor design for
   that page. The ready-made homepage is only used until you build the Home
   page in Elementor.

Optional pre-made Elementor layouts live in
`plugins/dog-father-control-center/templates/elementor/` and can be imported via
`Templates → Saved Templates → Import` (header/footer templates there require
Elementor Pro's Theme Builder, which is entirely optional since the theme already
provides a luxury header and footer).

## Replacing demo content

- **Services / Testimonials / FAQs:** edit or delete the demo entries under the
  Dog Father menu and add your own.
- **Gallery:** the demo items are placeholders — edit each and set a Featured
  Image to show real photos.
- **Hero image:** `Dog Father → Homepage → Background Image`.
